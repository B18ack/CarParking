# 🚗 CarParking

Игра на Unity про парковку автомобилей.

## 🎮 Что есть в игре

* Управление машиной
* Парковка в ограниченном пространстве
* Физика автомобиля

## 🛠️ Технологии

* Unity
* C#

## 🚀 Как запустить

1. Открыть проект через Unity Hub
2. Нажать Play
