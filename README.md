# 🚗 CarParking

CarParking — это 3D игра-симулятор парковки, в которой игрок управляет автомобилями, выбирается из парковки в ограниченном пространстве и проходит уровни с возрастающей сложностью.

## 🎮 Что есть в игре

🚗 Реалистичное управление автомобилем
🅿️ Парковочные места с ограничениями
🎮 Система уровней
📈 Увеличение сложности
🧩 Физика движения авто

## 🛠️ Технологии

* Unity
* C#

## What I learned
- Unity physics system
- Vehicle control mechanics
- Scene management
- UI system in Unity
  
## 🚀 Как запустить

1. Открыть проект через Unity Hub
2. Нажать Play
